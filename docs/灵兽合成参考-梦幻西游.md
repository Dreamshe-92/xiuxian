# 灵兽合成参考——梦幻西游炼妖/召唤兽体系

> 整理日期：2026-10-11。目的：为 xuxian 的灵兽合成玩法提供设计参考。
> 背景：万界道友的灵兽融合（两只 ≥30 级合成一只、结果随机、变异不可融）规则简单；梦幻西游的召唤兽体系是国内宠物玩法的鼻祖，深度高一个量级，值得作为合成系统的主参考。

## 一、梦幻西游炼妖核心机制（已核验）

### 1. 炼妖合成

- 两只 **≥30 级**召唤兽合成一只新召唤兽（与万界道友一致——万界就是抄的这条）；
- **结果随机**：可能是材料 1 的类型、材料 2 的类型，甚至可能是泡泡/大海龟这类低级废品；
- **资质与成长按规则继承双亲**——不是纯乱数，有可计算的期望；
- **合成可以突破原有资质上限**——这是高价值宠物的核心来源，也是炼妖存在的意义：不是抽奖，是**冲破天花板**。

### 2. 资质与成长（数值层）

- 资质分 **21 档**（1.00~1.20）；
- **变异召唤兽资质 = 普通档位 ×1.08**（变异的稀缺性直接体现在数值倍率上）；
- 成长率独立于资质，决定每级收益——"资质 × 成长"双轴构成宠物价值评估标准。

### 3. 打书（技能层）

- 用"魔兽要诀"给宠物教技能，但**会随机顶掉一项原有技能**——经典的"打书赌狗"；
- 技能数量 ≤2 时顶替概率另有规则（低技能数打书更安全）；
- 合宠出货以 **4 技能**居多，6~7 技能极稀有——技能格数量本身就是稀有度标尺。

### 4. 洗炼（重置层）

- **金柳露**把 95 级以下普通召唤兽洗回 0 级重新随机资质成长；
- **超级金柳露**用于 95 级以上，商城直购（60 仙玉/个）——**充值直接进入宠物经济**的通道；
- 玩家会在官方"炼妖盛典"活动期集中洗炼 → 官方用活动调节货币回收节奏。

### 5. 寿命与忠诚（持续消耗层）

- 寿命如同耐久：**每场战斗 -1，战斗死亡 -50**，逃跑不扣；
- 恢复靠**烹饪道具**（桂花丸/长寿面等，140 品桂花丸 ≈ 70 点寿命）——宠物消耗与**生活技能（烹饪）**联动；
- 长期日均消耗约 200 点寿命，一个月不补就废——**持续的金币回收泵**。

## 二、经济设计洞察（梦幻最值得学的地方）

1. **合宠是最大的灵石回收池**：结果全随机 + 材料直接消耗，玩家自发的"赌狗"行为完成了大规模货币沉淀；
2. **风险分层自洽**：攻略圈自发形成"低成本 2+3 技能胚子稳合"与"多技能极品冲 6/7 技"两条路径——赌注大小玩家自选；
3. **消耗-生产联动**：宠物寿命消耗 → 烹饪需求 → 生活玩家赚钱 → 战斗玩家花钱，**系统间形成内循环**；
4. **充值入口藏在道具里**：超级金柳露商城直购，但每日限购——付费不打断经济，只加速；
5. ⚠️ **反面教训**：结果完全随机无保底，失败归零，挫败感极强；且极品可现金交易（藏宝阁）催生工作室。xuxian 若做合成，**需要比梦幻多一层保底/补偿设计**。

## 三、对 xuxian 灵兽合成的落地建议

在万界道友现有规则（两只 ≥30 级、可预览、变异不可融）基础上，吸收梦幻的深度：

| 机制 | 采用建议 |
|---|---|
| 合成随机出结果 | ✅ 保留，但**加保底**：连续 N 次未出目标品阶，下次提升概率（缓解梦幻式挫败） |
| 资质成长继承双亲 | ✅ 必抄：继承规则透明可算，玩家才有"配种"策略感（合成从赌博升级为炼金） |
| **合成可突破资质上限** | ✅ 必抄：给合成一个超越"抓宠"的核心价值——天花板突破者只能靠合成 |
| 技能格 + 打书 | ✅ 建议抄：技能格数做稀有度标尺；技能书可打可顶（随机顶替可软化：顶替时三选一） |
| 洗炼重置 | ✅ 可抄：包装成"灵兽洗髓/洗灵"，道具驱动，可做商城或活动产出 |
| 寿命/忠诚消耗 | ◐ 简化采用：死亡掉寿命对休闲游戏太狠，可只做"喂食恢复体力"的轻消耗，与灵田/烹饪联动 |
| 变异 ×1.08 资质倍率 | ✅ 可抄：变异的稀缺用数值倍率表达，规则极简 |
| 现金交易 | ❌ 不做：虚拟资产现金化带来的工作室与法律风险，xuxian 阶段不碰 |

**一句话总结**：万界道友的融合只是"抽卡"，梦幻的炼妖是"**透明遗传学 + 天花板突破 + 三层持续消耗**"的完整经济系统——xuxian 取后者的结构，用保底机制替换其纯赌性。
