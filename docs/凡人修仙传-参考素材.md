# 《凡人修仙传》参考素材——面向 xuxian 的设定提炼

> 整理日期：2026-10-11。目的：为 xuxian（修仙文字交互游戏）提供世界观与数值参考。
> 范围说明：原作约 2400+ 章/700 万字，本文不逐字复述，只提炼**可游戏化的设定结构**；关键数值（境界/寿元/品阶/妖兽等级）经网络检索核验。
> 重要背景：竞品《万界道友》的世界观基本直接取材本作（地图：天南/越国/黄枫谷/坠魔谷/乱星海/大晋/慕兰草原；术语：真灵根/变异灵根；世界频道玩家直接用"韩立"做道号），说明这套设定的游戏适配性已被验证。

## 一、境界与寿元体系（可直接抄的数值表）

三段式：下境界（人界）→ 中境界（灵界）→ 上境界（仙界）。每境分初期/中期/后期/圆满（部分有大圆满）。

| 境界 | 寿元参考 | 设计含义 |
|---|---|---|
| 炼气期 | 百余岁 | 新手期，寿元压力低 |
| 筑基期 | 约 200+ 岁 | 正式修士门槛，"凡人与修士"的分水岭 |
| 结丹期（金丹） | 约 500 岁 | 一方强者，宗门长老级 |
| 元婴期 | 约 1000 岁 | 顶级战力，元婴可夺舍/遁逃（死亡惩罚设计素材） |
| 化神期 | 约 2000 岁 | 人界天花板 |
| 炼虚期 | 约 10000 岁 | 灵界内容 |
| 合体期 | 数万年 | |
| 大乘期 | 数十万年量级 | |
| 渡劫/真仙 | 近乎无穷 | 转生/飞升 = 赛季重置的叙事包装 |

**对 xuxian 的直接借鉴**：竞品的"闭关耗寿元、突破涨寿元上限"就是这个表的玩法化。寿元是硬通货——玩家用寿命换修为，突破换回更长的寿命，形成"以命换道"的核心循环。

## 二、灵根体系（开局抽卡的原始模板）

| 灵根 | 设定 | 游戏化 |
|---|---|---|
| 天灵根 | 单一五行属性，修炼速度数倍，**结丹无瓶颈** | SSR：数值强 + 突破免检 |
| 异灵根/变异灵根 | 雷/风/冰等变异属性，速度仅次于天灵根 | SR：特殊流派（剑修/雷法）专属 |
| 真灵根/普通多灵根 | 两三种属性，中庸 | R：标准开局 |
| 伪灵根 | 四五行混杂，修炼奇慢（韩立即四属性伪灵根） | N 起点 + **成长剧情钩子**（后天补全灵根） |

**借鉴点**：①最高稀有度不是终点——韩立伪灵根逆袭是全书母题，"烂开局+后天改命"（对应竞品的"重塑命格/归元洗髓"）比"开局 SSR"更有长线叙事价值；②灵根可借灵物补全（器灵根/丹灵根）→ 天然的养成收集线。

## 三、物品与经济

- **灵石**：下品/中品/上品（灵界用仙石）——通用货币，兼作修炼资源（可打坐吸收），"货币即燃料"。
- **装备阶梯**：法器（上中下品+顶阶）→ 法宝（结丹可用，需神识祭炼认主）→ 古宝/通天灵宝 → 玄天之宝。**"祭炼认主"= 装备绑定机制的原型**。
- **生产四支线**：炼丹（延寿/突破/战斗丹药分级明确）、炼器、符箓、阵法；另有**傀儡**（挂机/多线程玩法原型：韩立靠傀儡军团以弱胜强）。
- **交易场景**：坊市摆摊、拍卖行（压轴竞价桥段）、万宝楼类大型商号——玩家经济的完整原型链。

## 四、妖兽与灵兽

- 妖兽 13 级，每级分初中上阶；**1 级≈炼气、2 级≈筑基初期**……逐级对应修士境界；1-6 级称妖兽，7 级以上称**妖修**（可化形）。
- 妖丹/妖兽材料是炼丹炼器核心原料 → 打怪-生产循环的素材链。
- 收服/契约灵兽（韩立的啼魂兽、豹麟兽等）→ 竞品"灵兽袋/融合/出战位"的直接出处。

## 五、可游戏化的核心设定（xuxian 最值得拿走的）

1. **掌天瓶**（韩立的金手指）：神秘小瓶催熟灵草——"每日限量生长加速器"。原型级创意：把每日签到做成世界观内的神器，而非系统弹窗。
2. **神识**：探查/传音/御物/祭炼多用途——可作为"解锁功能"的资源（神识强度=功能开关）。
3. **遁术/御器飞行**：地图移动的包装（竞品的"云游"即此）。
4. **瓶颈/心魔/天劫**：竞品已验证的三段突破机制，原著本就是"积攒多年+机缘+赌命"的叙事。
5. **正道/魔道/佛宗三系**：阵营差异=流派差异（对应竞品五宗门的佛魔/雷/剑/五行/幽魂）。
6. **秘境/遗迹**：虚天殿、坠魔谷、血色试炼——限时开放、多人争宝、按境界准入（竞品秘境的境界门槛即此逻辑）。
7. **散修 vs 宗门**：两条生存路线（自由但资源匮乏 vs 有靠山但受约束）——玩家身份选择的原型。
8. **本命法宝/夺舍/坐化**：死亡与重生的世界观化处理（软性死亡惩罚的叙事包装）。

## 六、叙事风格参考

- **"凡人流"母题**：无背景、资质平庸的主角靠谨慎、苟、长线规划登顶——与"重氪碾压"相对，天然适配放置/挂机/文字游戏的慢节奏。
- **日常颗粒度**：坊市捡漏、闭关数年、炼丹炸炉、斗法赌斗——全是现成的"文字事件"素材。
- **命名风格**：动词+名词的功法名（青元剑诀/大衍诀）、"某老魔/某道人"的称呼体系、灵草矿物名（千年灵草/精金）——文案包装可直接套用此语法。

## 七、深度补充（第二轮：原著结构与细节挖掘，2026-10-11）

> 经网络检索核验：全书 767.6 万字、2611 章，2008-2013 年连载。本节补充第一轮未覆盖的结构与细节。

### 1. 三界篇结构 = 版本分层路线图（已核验）

| 篇章 | 内容 | 游戏化原型 |
|---|---|---|
| 人界篇 | 七玄门起步→黄枫谷→结丹→元婴→化神→飞升 | 正式服主体内容 |
| 灵界篇 | **空降灵界"法力全无，从零开始"**，重修至大乘 | **资料片/新服 = 带着设定重置数值** |
| 仙界篇 | 飞升即被伏击，**元婴被封、记忆缺失跌落下界**，修玄仙再上来 | **转生/轮回玩法**：高层重开+保留部分遗产 |

原著两次"重开"（灵界清零、仙界失忆跌落）正是现代游戏的赛季重置与转生系统的叙事原型——**换地图必须伴随战力重置**，否则旧内容 instantly 过期。long-term roadmap 可按"人界资料片→灵界资料片"规划。

### 2. 七玄门新手村拆解（仅取通用经验）

> **xuxian 设计决定（2026-10-11）**：不做"凡人门派"角色扮演开局——玩家直接以修士身份创建角色入世（与竞品万界道友一致），凡人阶段仅作原著背景考据保留。

韩立前几章的节奏虽不照搬，但有三条与"角色扮演"无关的通用经验仍然有效：

1. **生产先于战斗**：韩立第一个学会的是认药采药——新手引导先教采集/炼制，再教打架（竞品引导链"洞府→储物袋→舆图"同理）；
2. **功法分层数值化**：《长春功》一层层往上练、以年计进度——修炼按"层"计是放置游戏的叙事底座；
3. **时间跳跃**：原著一句"数年后"跳过枯燥期——正是放置/挂机"离线收益"的叙事包装。

（原七玄门剧情细节——凡人武学门派、夺舍危机等——属角色扮演叙事，不采用。）

### 3. 功法与神通名词库（包装语法样本）

- 主功法：《长春功》（木属性长生功）、《青元剑诀》（剑修，**共十三层**，含青元剑芒/护体剑盾/剑影分光术/大庚剑阵）、大衍诀（炼神识）、元磁神光（克飞剑法宝）、梵圣真魔功（魔道炼体）；
- **辅助功法**（被动位）：三转重元功；
- 结构规律：**主功法（含 N 层+若干神通）+ 辅助功法（被动）+ 独立神通/秘术**——三层技能架构，竞品"心法+神通"即此；
- 神识可专门炼（大衍诀）→ "神识强度"可做成独立养成线。

### 4. 法宝成长与收集

- **青竹蜂云剑**：金雷竹炼制 **72 口**，可布大庚剑阵——**套装收集系统**的原型（集齐 72 把解锁剑阵形态）；
- **本命法宝祭炼**：法宝需神识祭炼认主、随主人成长——装备绑定+养成的叙事化；
- 法宝随境界更替（人界法宝→灵界重配）→ 装备淘汰曲线的世界观化。

### 5. 掌天瓶机制细节（每日神器的完整设计）

吸收**月光/日月精华**凝绿液 → 浇灌催熟灵药 → 炼丹突破；后期揭示**还能加速法则修炼**。三个设计要点：①资源来源有世界观解释（月光）；②**每日限量**（白天攒夜里用）= 天然日活钩子；③金手指随版本升级（催熟→加速法则）——签到系统要做到"神器随资料片进化"。

### 6. 传承与机缘系统

韩立的关键能力多来自**前辈遗产**：大衍神君（傀儡术+大衍诀）、墨大夫（药理+长春功，附带夺舍阴谋）——"遇前辈→获传承→担因果"三段式，可做成 roguelike 秘境事件的模板（竞品秘境的"坐化遗骸"标签即此）。

## 八、对 xuxian 的落地建议

1. **数值骨架直接用第一节表格**（境界-寿元），这是被竞品验证过、且原著背书的成熟设计。
2. **开局抽卡用灵根四档**，但把最低档设计成"可后天补全"的成长线，而不是纯负反馈。
3. **每日核心循环绑一个"掌天瓶"式神器**，让签到/挂机有世界观内解释。
4. **版权注意**：借鉴设定体系与数值结构没问题（思想不受版权保护），但**不要直接使用原著专有名词**（韩立/黄枫谷/掌天瓶/青元剑诀等）——竞品大量直接挪用属于灰色地带，xuxian 应做原创包装（语法可学，名字自起）。
5. 原著 "人界→灵界→仙界" 三段世界 = 天然的赛季/版本分层， long-term roadmap 可以直接按此规划。
