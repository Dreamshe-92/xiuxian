# 小说参考素材二：斗破苍穹 / 诡秘之主 / 遮天

> 整理日期：2026-10-19。定位：在凡人修仙传（境界骨架）与梦幻西游（灵兽经济）之外的三根系统设计柱子。
> 分工：**斗破=收集/合成/导师，诡秘=职业树/扮演法，遮天=体质/全服事件**。
> 关键数值经网络检索核验（来源见文末）；版权原则同前——借鉴结构不搬专名。

## 一、斗破苍穹：收集与合成的范式

### 1. 异火榜（收集图鉴的天花板设计）

- **23 种异火编制成榜**，每火有排名、颜色、特性、出处：帝炎（22 火融合之色）> 虚无吞炎（黑色，吞噬万物）> 净莲妖火（净化万物，以情绪为引入体）> 金帝焚天炎 > … > 玄黄炎（垫底）。
- 收服异火需**炼药师辅助**（如收青莲地心火需五品"血莲丹"）——收集品之间有依赖关系。
- **焚决**：靠吞噬异火进化的功法，吞的火越多排名越高，功法越强——**功法成长与收集进度绑定**。

**可游戏化**：
- "图鉴排行榜"设计：收集品带全局排名与图鉴完成度，垫底品也是图鉴的一格（收集欲拉满）；
- **吞噬合成**：低阶收集物融合成高阶（异火互吞=灵兽融合的姊妹设计），合成产物继承特性；
- 收集品解锁功法形态——集齐 N 件激活"焚决进化"，装备/技能与图鉴联动。

### 2. 炼药师等级（生产职业话术）

- 丹药**十品**：半成品（不入品）→ 一至九品 → 帝品；每品内再分低/中/高/巅峰四层；
- **丹药灵智**：七品初具灵智、八品能与人斗、九品可化人形——产出品本身是"活物"；
- 九品内分宝丹/玄丹/金丹，**炼制高阶丹引天雷**（黑魔雷/九玄金雷）——生产玩法带仪式感和风险。

**可游戏化**：炼丹等级=玩家生产职称（可展示）；高阶炼制=高风险高仪式感事件（引雷=全服可见的大事件）；"丹药有灵"可做高级产出的彩蛋（开鼎出的九品丹自己会跑）。

### 3. 药老（随身导师范式）

灵魂状态的老师傅住在戒指里：教功法、辨宝物、关键时刻救命，自身有身世谜团（被害的炼药宗师）。
**可游戏化**：新手引导 NPC 的深化版——导师不发光标，而是**有自己剧情线的随身角色**；引导完成后导师线转为长线支线。

## 二、诡秘之主：职业树与扮演法（AI 绑定核心）

### 1. 途径-序列体系（职业树范本）

- **22 条途径 × 每条 10 个序列（9 最低 → 0 最高）**，序列 0 = 该途径真神；
- 晋升链示例（愚者途径）：占卜家 → 小丑 → 魔术师 → … → 愚者——**每级有名字、有配方、有晋升仪式**；
- 途径之间有相邻/对立关系，非凡特性源自神话存在（部分途径特性来自外神）。

**可游戏化**：把"宗门×流派"升级为**途径表**——每条途径一张十级序列表，玩家选途径后逐级解锁；序列名本身就是身份感（"我是序列 7 魔术师"）。

### 2. 扮演法（与 AI 文字交互的天然粘合剂）★ 重点

- 喝下魔药获得力量后，必须**"扮演"魔药名称对应的角色**才能消化魔药；
- 扮演越到位消化越快，消化不完全有**失控成怪物**的风险；
- 演绎的是"身份"而非"数值"——占卜家就要像占卜家那样思考行事。

**可游戏化（xuxian 的杀手锏候选）**：
- 玩家选择功法/命格后，**AI 持续评价玩家的行为是否符合该身份**（"你修的是问剑之道，但三个月没碰过剑"）——扮演评分影响修炼速度/突破成功率；
- 把竞品的"感悟"数值升级为"**道心/扮演度**"：由 AI 从玩家行为日志生成评价，而不仅是闭关数值；
- 失控机制=突破失败的具体化：扮演失败不是扣数值，而是进入"心魔形态"特殊状态（对应道诡异仙方向）。

### 3. 值夜者小队/塔罗会（秘密结社）

非凡者组队对抗超自然威胁；塔罗会=成员互不知身份的秘密聚会，靠信物召集。
**可游戏化**：宗门的进阶形态——**匿名结社玩法**（玩家以道号相称的私密组织、定期聚会事件），社交系统的轻量化方案。

## 三、遮天：体质与全服事件

### 1. 体质谱（开局资质 2.0）

- 数十种特殊体质各有排名与代表人物：混沌体 / 先天圣体道胎 / 苍天霸体 / 荒古圣体 / 太阴体 / 太阳体 / 元灵体…；
- **圣体 vs 霸体宿敌叙事**：两大体质万年恩怨——体质不只是数值，自带**阵营对立剧情**；
- 荒古圣体"到叶凡时代资源贫乏已不适合修炼"——**强体质带时代性缺陷**（版本答案会过期）。

**可游戏化**：灵根四档的升级方案——体质=灵根+命格二合一（既有资质数值又有专属剧情钩子）；宿敌体质=玩家间天然对立阵营；"过气强体质"=版本平衡的叙事化处理。

### 2. 秘境式境界命名（另一套话术库）

轮海秘境（苦海→命泉→神桥→彼岸）→ 道宫（五脏五境）→ 四极 → 化龙 → 仙台——**境界藏在"秘境"里，每层有画面感**。
**可游戏化**：境界命名的备选话术库（若不想直接用凡人的炼气/筑基体系），苦海/命泉/神桥天然适合做修炼室各阶段的名字。

### 3. 七大生命禁区（周期性全服事件）

荒古禁地、太初古矿、上苍、仙陵、神墟、不死山、轮回海——禁区蛰伏**自斩修为苟活的自封至尊**，定期发动黑暗动乱索取血食。
**可游戏化**：
- **周期性服务器事件**的世界观天花板：禁区=常驻威胁，"黑暗动乱"=周期性全服危机事件（全服玩家协力/献祭/抵御）；
- 比竞品"天道广播"更强的紧迫感设计：广播是喜报，禁区是倒计时；
- 自封至尊=世界级 BOSS 的叙事解释（为什么 boss 一直在那：苟了几万年）。

## 四、三本组合到 xuxian 的落地建议

| 系统 | 主要参考 | 落地 |
|---|---|---|
| 开局资质 | 遮天体质 + 凡人灵根 | 体质=灵根数值+命格剧情二合一，带宿敌对立与时代缺陷 |
| 职业成长 | 诡秘途径表 | 宗门×流派改为途径-序列表，逐级解锁带身份感 |
| 修炼核心 | 诡秘扮演法 | "道心/扮演度"由 AI 评价玩家行为生成——**AI 文字游戏的核心差异化** |
| 收集合成 | 斗破异火榜 + 梦幻炼妖 | 收集图鉴带排行榜；低阶物融合高阶；图鉴完成度解锁功法形态 |
| 生产职业 | 斗破炼药师 | 炼丹职称可展示；高阶炼制引"天雷"（全服事件感）；丹药有灵彩蛋 |
| 新手引导 | 斗破药老 | 随身导师 NPC 带自身剧情线，引导完成后转长线支线 |
| 全服事件 | 遮天禁区 | 常驻禁区+周期黑暗动乱=全服危机事件，配合天道广播 |
| 社交结社 | 诡秘塔罗会 | 匿名结社（私密组织玩法），轻量社交 |

**优先级建议**：扮演法（道心系统）> 收集合成 > 全服事件——扮演法是 xuxian 区别于万界道友的**核心创新机会**，其余是体验增强。
