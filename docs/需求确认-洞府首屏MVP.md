# 需求确认 · 第四轮：洞府首屏与 MVP 闭环范围

> 确认日期：2026-10-23（ZCode 侧问答调研第四轮，用户拍板）。依据：`docs/万界道友-游戏流程调研.md`（洞府枢纽实测）。
> 配套：前三轮（战斗指令集 / 修炼循环 / 角色创建）。**本文档收尾后 MVP 需求全部闭环，可进入里程碑拆分。**

## 一、四项决定

| # | 决策点 | 决定 | 说明 |
|---|---|---|---|
| 1 | 洞府设施 | **核心五件套** | 修炼室（闭关/突破）、储物袋、灵兽袋、灵眼之泉（恢复/灵石沉淀）、外出入口 |
| 2 | 外出结构 | **单一野外点** | 一个青溪坡式地点（3~5 种灵兽、寻觅耗灵气），完整舆图后续版本 |
| 3 | 引导任务 | **当下要事卡** | 首页任务提示区 + 5 步新手链 + 突破提醒，无完整任务系统 |
| 4 | 每日钩子 | **每日占卜** | 骰子+卦象+**模板库解读文案**（无 AI 依赖）+小道具奖励 |

## 二、洞府首屏布局规格（DOM 覆盖层，对齐竞品信息架构）

```
┌──────────────────────────────────────────────┐
│ 顶部状态条：气血 | 法力 | 修为 | 感悟 | 境界 | 灵气 | 灵石   │
├──────────────────────────────────────────────┤
│ 「当下要事」卡（新手链进度 / 突破提醒 / 占卜提醒）  │
├──────────────────────────────────────────────┤
│ 「洞府各处」：                                  │
│   🧘 修炼室（闭关 | 突破 两页签）                  │
│   🎒 储物袋（40 格 + 装备位 6）                   │
│   🐯 灵兽袋（名册 + 出战位 + 首发标记）             │
│   💧 灵眼之泉（投灵石回满血蓝）                    │
│   ⛰️ 外出·青溪坡（寻觅灵兽 → 战斗）               │
├──────────────────────────────────────────────┤
│ 侧栏/角落：🎲 每日占卜                            │
└──────────────────────────────────────────────┘
```

- MVP 无底部导航（洞府即首页，五入口即全部）；无宗门/声望/世界频道字段；
- 修炼室/储物袋/灵兽袋/灵泉均为**面板**（DOM 覆盖层），不切场景；仅"外出"进入战斗流程。

## 三、新手链（当下要事卡 5 步）

```
① 凝气成形（完成角色创建）
② 入世安身（看完入世剧情，到达洞府）
③ 初次闭关（开启状态式闭关并结算一次收益）
④ 初临青溪（完成一次外出寻觅+一场战斗）
⑤ 结缘灵兽（成功捕捉一只灵兽）
→ 完成后要事卡转为：突破提醒（修为≥60%）/ 占卜提醒 / 后续版本接任务系统
```

每步完成给小额奖励（灵石/灵气），卡片可折叠不打扰。

## 四、每日占卜规格（无 AI 依赖版）

- 掷三骰（点数和 3~18）→ 按点数段映射卦象池（每段 3~5 卦，共约 40 卦）；
- 卦象 = 卦名 + 卦诗一句 + **模板化解读**（选占卜方向：修炼/战斗/捕捉/突破 → 解读从对应方向文案库拼接，纯模板无 AI）；
- 奖励：小道具（聚灵符类=灵气小额回复）每日一次；
- `data/tables/divination.json` 承载全部文案；AI 增强解读留扩展位（后续接 AiNarrativeService）。

## 五、MVP 经济闭环验证（五件套下自洽）

```
灵石：来源=战斗掉落+占卜小奖+新手链奖励 → 去处=灵眼之泉恢复（沉淀口）
灵气：来源=时间自动回复 → 去处=外出寻觅+闭关消耗
寿元：来源=筑基大突破涨上限 → 去处=闭关持续消耗
修为/感悟：闭关产出 → 突破消耗/加成
```

四个资源全部有源有汇，闭环成立。坊市/生产延后不影响 MVP 自洽（灵石用途偏薄是已知取舍，首版本可接受）。

## 七、对架构的影响

1. `HubScene` = 洞府五入口 + 状态条 + 要事卡 + 占卜角标（DOM 覆盖层为主，Phaser 仅洞府背景演出）；
2. 战斗流程：外出（寻觅面板）→ `BattleScene`（Phaser 演出 + DOM 指令条）→ `ResultOverlay` 收束 → 回洞府；
3. 野外点数据进 `data/levels/wild-qingxi.json`（灵兽组/等级带/消耗）；
4. 新手链状态机放 `systems/quest/`（轻量实现，5 步枚举）。

## 八、MVP 需求全部闭环 ✔

四轮问答定稿：**角色创建 → 入世 → 洞府（修炼/外出/恢复/背包/灵兽）→ 战斗（捕捉/自动）→ 突破链（炼气→筑基）→ 每日占卜**。
