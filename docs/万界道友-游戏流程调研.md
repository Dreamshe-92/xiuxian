# 万界道友（client.daoyou.org）游戏流程调研

> 调研日期：2026-10-11。目的：作为 xuxian（修仙文字交互游戏）项目的玩法与结构参考。
> 调研方式：ZCode 浏览器自动化实际注册账号、创建角色、走完新手流程。以下全部为一手实测记录。

## 一、产品概览

- **形态**：网页端修仙文字交互游戏（React SPA，PWA 可安装），带 MMO 社交要素（世界频道、组队讨伐、全服传闻广播）。
- **核心特色**：角色创建和剧情推进大量使用 AI 生成（心念生成身世、剧情"落字中"动态生成、闭关"修炼中"异步结算）。
- **美术风格**：纸墨/水墨风（纸张背景 webp、水墨鸟瞰舆图、角色"墨像"头像），标题称"在纸墨之间落下道字"。

## 二、完整新手流程（实测顺序）

```
登录 → 角色创建(凝气) → 入世剧情 → 洞府教学 → 角色页教学 → 储物袋教学
     → 许伯指路剧情(分支选择) → 世界舆图教学 → 选宗门(入山演出) → 拜入宗门
     → 宗门NPC对话(领俸) → 属性分配 → 修炼室闭关 →（循环：闭关→修为→突破）
```

### 1. 登录与角色创建（`/login` → `/game/create`）

三种登录方式：邮箱验证码（首用自动注册）、密码登录、GitHub OAuth。

角色创建叫"凝气"，三步：

1. **以心念唤道**：输入一句愿望描述（≤200 字，每日 6 次，按邮箱+网络双计数）。示例 placeholder："我想成为一位靠炼丹逆袭的废柴少主……"
2. **AI 生成道身 + 命格抽选**：
   - 道身：姓名、境界（炼气·初期）、身世、性格、背景长文、**天道评语**（AI 解释为什么这样设计，含资质评分 85）、年龄 17/寿元 114/性别/气血 520/法力 350。
   - 灵根：属性（金/风等）+ 品阶（真灵根/变异灵根…）+ 强度数值（69/77）。
   - 根基属性：六维各 15 起步 + 派生物攻/物防/法攻/法防。
   - **先天命格 6 选 3**：每条命格 = 名称 + 品阶（凡品/灵品/天品）+ 数值效果 + 风味文案。可用"逆天改命(5)"重抽。
   - "重凝"可重新生成（消耗当日次数）。
3. **保存道身 → 确认弹窗（姓名/境界/灵根）→ 入世**。

### 2. 入世剧情（`/game/story`）

- 文字交互主界面：场景卡（地点·时间如"洞府·清晨"）+ 章节名 + 逐字打字机效果 + 旁白/NPC 对白/主角对白（对白带说话人名）。
- 操作按钮：继续 / 回看 / 稍后再看；生成中显示"落字中……"。
- **分支选择**：剧情节点弹出选项组（如"一 宗门能教我些什么？二 先看看舆图"），选择影响后续。
- 幕结束显示"可以离开这一幕了"。

### 3. 洞府主界面（`/game`，游戏枢纽）

- **顶部状态栏**：气血/法力、修为(0/500)、感悟(0/200)、境界(炼气·初期)、天地灵气(200/240，随时间恢复)、灵石、声望、状态(安稳)、宗门、躯体制(凡躯)。几乎全部可点击进详情。
- **当下要事**：新手任务卡"青溪初行"（链式引导：洞府→角色→储物袋→舆图→山门）。
- **洞府各处**（每个都是独立路由）：
  - 修炼室 `/game/retreat`、炼丹房 `/game/craft/alchemy`、炼器室 `/game/craft/refine`、悟道室 `/game/enlightenment`、阵纹室 `/game/inscriptions`、练功房 `/game/training-room`、灵眼之泉(休养) `/game/inn`、储藏室、灵田 `/game/spirit-field`、育兽室 `/game/beast-room`
- **出洞府**：外出云游(副本) `/game/dungeon`、坊市 `/game/map-v2?intent=market`、蜃楼幻境(爬塔) `/game/tower`、拍卖行 `/game/auction`、组队讨伐 `/game/hunt-team`
- **侧栏**：每日占卜 `/game/divination`、近期战札（战斗记录）。
- **系统/世界频道**：底部浮动消息条，广播全服事件（某玩家捕获变异灵兽、某玩家炼成法宝展示）与玩家组队招募。
- **底部导航**：角色 / 储物袋 / 洞府 / 道友传音(邮件) / 展开。

### 4. 教学弹窗（分页面触发，各 2-3 步）

- 洞府页 3 步：洞府是落脚处 → 灵眼之泉用于休养别浪费 → 出洞府的去处。
- 角色页 3 步：名字/境界/宗门归属（散修显示散修）等。
- 储物袋页 3 步：随身物品 vs 洞府储藏室 → 格子/筛选/整理 → **装备位 6 个：法冠👑、法兵⚔️、腰封🎗️、灵佩📿、法衣🥋、云履👢**（"兵器放袋里不算装备，铸好第一件兵器再穿戴"）。
- 舆图页 3 步、山门页 2 步。

### 5. 世界舆图（`/game/map-v2`）

- 层级：人界总览 → 区域 → 地点分类 → 地点。画卷/文字两种显示模式，可搜索。
- 人界开放区域 6 个：天南、慕兰草原、乱星海、大晋皇朝、北境冰原、南疆；未开放 6 个（天澜草原等，标注"未开放"）。
- 天南地点按类型分组：灵兽出没地 6、秘境 9、坊市 6 等（太岳山·青溪坡=新手练手点）。

### 6. 选宗门（`/game/sect/onboarding`）

5 个宗门，各有定位与两流派：

| 宗门 | 定位 | 流派 |
|---|---|---|
| 红尘剑宗 | 剑修，入世问剑 | 斩尘证道 / 万剑归一 |
| 无相禅宗 | 佛魔同修，以身渡厄 | 佛心济世 / 魔心修罗 |
| 天衍圣地 | 五行法术连携 | 衍法天师 / 执衡真君 |
| 幽都 | 蚀魂叠层、禁疗耐控 | 拘魂锁命 / 蚀魂摧形 |
| 九劫天宫 | 雷法淬体 | 霹雳真君 / 踏雷天尊 |

入山流程：5 幕演出（带 AI 插画，如"山门朝向山下城郭，负剑弟子沿石阶往来"），可上一幕/返回/换宗，最后"拜入"。实测选择红尘剑宗。

### 7. 宗门舆图（`/game/sect`）与 NPC

- 水墨鸟瞰图，可拖动缩放，15 处设施：问剑堂、剑录阁、照影崖、试剑台、执事堂、百业院、灵脉矿场、药田、山门（开放）；宗门宝库、养剑室、丹房、铸剑坊、私人洞府、护山大阵（未开放）。
- 点设施 → 详情弹窗 → "进入"。问剑堂内 NPC 对话为选项菜单制：
  - 掌籍执事顾怀真：查验身份玉牒（记名弟子 + 30 贡献）、同门名录、宗门公告、贡献榜。
  - 俸禄执事柳七：**每周俸禄 1,650 灵石**，对话内领取入账。
- 宗门机制：记名弟子→正式晋升（事务堂传功长老）、宗门贡献、周俸。

### 8. 属性分配（`/game/cultivator/attributes`）

- 角色页 4 个标签：人物属性 / 先天设定 / 所修功法 / 肉身修炼。
- 六维根基：体魄、力道、灵力、根骨、身法、神识（各 15 起，新手送 25 点）。
- 派生战斗属性：物攻/法攻/物防/法防/速度（实测 +10 力道 +7 根骨 +8 身法 → 物攻 65、物防 58、法防 69、速度 46）。
- 确认弹窗明示：**重新分配需消耗"归元洗髓符"**（洗点有代价）。
- 另有"修改名号"（称号系统）。

### 修炼升级全链路（实测打通：炼气初期 → 炼气中期）

**闭关**：输入年限 1~200 → 消耗寿元（10 年/次）+ 天地灵气（10 年=4 点）→ 结算弹窗"闭关回响"：修为 +59~72（**收益随机浮动**）、感悟 +2~4。修为丹可增益。**修为 80% 后进入瓶颈期，闭关效率降低**，提示转副本/战斗寻求突破（软性逼玩家去历练）。

**突破**（修炼室第二个标签，实测成功一次）：

- 三档火候：**强行突破**（修为≥60%，风险最高）／**常规突破**（≥80%，主流）／**圆满突破**（100% 且感悟≥50，最稳）。
- **成功率推演公式**（确认弹窗明示）：综合基础率 47.5% × 修为进度加成 95.0% × 道行感悟加成 104.3% + 命格机缘 +1.5%（"新手保护"命格生效）= 最终 49.0%。
- **失败代价**：修为损耗、法力涣散、感悟降低；**连续失败 3 次生"心魔"**，影响后续突破。
- 每次突破消耗 20 天地灵气。
- **成功结算**（AI 生成"冲关回响"叙事）：境界提升（炼气初期→中期）、**六维各 +5 自动成长**、**再送 25 自由属性点**、修为清零且上限提高（500→600）、气血/法力上限上涨、寿元上限上涨。

**属性分配**：每次突破后重复"六维加点"决策（派生物攻/物防/法防/速度），洗点需道具"归元洗髓符"。

**肉身修炼**（角色页第 4 标签，与境界平行的第二条成长线）：

- **五轨炼体**：皮肤（减物理伤）/ 筋骨（增物理伤）/ 脏腑（增法伤与封印命中）/ 气血（增血上限与治疗量）/ 元神（减法伤与被封概率），各 Lv0 起步、进度 0/100。
- **肉身阶位**：凡躯 → 铜皮 → …（单轨上限 Lv5，总等级达标进阶）。
- **洗髓**：破限机制，破限给自由属性点。

**所修功法**（角色页第 3 标签 + 宗门剑录阁，实测完整）：

- **按境界开功法位**：炼气位（上限 6 部）→ 筑基位 → 金丹位 → 元婴位，随境界解锁；学习需对应境界的"功法玉简"（道具，来源：宗门/坊市/掉落）。
- **红尘剑宗六卷心法**（练气阶段可修，剑录阁守阁长老温不言处研习）：
  - 问剑证道总纲（**主心法**）：研习加物理攻击；关联神通：断尘（3段连击）、惊鸿掠影、乘胜追击
  - 剑煞破军录：加命中；关联神通：破极剑意（队友物攻无视目标 10% 物防，5 回合）
  - 伏锋候时篇：加物理防御；关联神通：惊雷（蓄力：耗 5% 气血跳过当回合，次回合强化自动攻击）
  - 惊鸿逐影诀：加速度；暂无关联神通
  - 裂阵沉锋章：加气血上限；关联神通：临渊（最多 3 目标 AOE，心法 120 级解锁）
  - 澄神洗剑经：加封印抵抗；关联神通：剑心通明（自增法防封抗）、剑龙吟
- **研习消耗修为+灵石**：研习 1 级 = 60 修为 + 200 灵石——修为不只是突破资源，也是学技能的资源（双消耗设计）。
- **主心法锁**：分支心法等级不可超过《问剑证道总纲》，强制先点主线。
- 战斗中的神通等级即来自心法研习等级（战斗里用的"断尘 1 级"就是总纲 1 级自带的）。

**境界阶梯**（从世界频道与突破体系综合）：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫（飞升台），每境界分初期/中期/后期/圆满。

**资源循环总览**：寿元+灵气 →（闭关）→ 修为+感悟 →（突破）→ 境界+属性+上限 → 支撑更高强度战斗/历练 → 获得灵石/材料/功法 → 反哺修炼。瓶颈期与心魔机制防止无脑挂机，把玩家推向内容循环。

## 三、值得 xuxian 借鉴的设计点

1. **AI 生成角色创建**：一句心念 → 完整身世 + 数值 + 天道评语（AI 自评），让开场即个性化；每日限次防滥用。
2. **剧情/玩法穿插的引导链**：不是纯弹窗教学，而是"许伯"NPC 剧情串起洞府→舆图→山门，教学弹窗按页面就地触发（每页 2-3 步）。
3. **文字交互的分幕结构**：场景卡（地点·时间）+ 说话人标注 + 打字机 + 分支选项 + "回看"历史，异步生成时给"落字中"状态。
4. **数值骨架清晰**：六维根基 → 派生战斗属性；修为/感悟/寿元/灵气四资源互相制约（闭关花寿元和灵气，突破看修为和感悟）。
5. **命格（词条）系统**：品阶 + 数值效果 + 风味文案，6 选 3 + 付费重抽，开局即有 build 差异。
6. **宗门作为内容分包**：每宗门 = 专属剧情演出 + 舆图 + NPC + 流派心法，把 MMO 公会做成单机内容包。
7. **异步结算 + 全服广播**：炼丹/炼器/捕兽成功后广播给全服（"修仙界传闻"），制造活的世界感。
8. **品阶术语体系**：凡品/灵品/天品（命格）、真灵根/变异灵根（灵根）、凡躯（体制），全套修仙话术包装数值系统。

## 四、社交系统速记（道友传音 + 世界传音，实测补充）

### 道友传音（`/game/mail`，即邮件）

- 两个标签：**收件玉简**（收件箱）/ **好友名录**（好友列表）。
- 收件箱：列表（标题+日期+正文摘要），带附件的邮件有 🎁 标记；支持一键领取全部附件、全部已读；侧栏显示"已载 X 封 / 未读 / 待领附件"。
- 邮件详情弹窗：精确时间戳 + 正文 + "🎁 附赠物品"区（如 灵石 ×2.00万）+ 领取按钮。
- 官方邮件用途实测：版本修复公告（v0.4.5 更新日志）、新手礼包（含 2 万灵石）、兑换码通知——**公告也走游戏内邮件，修仙包装**。
- 好友名录：邀请制（分享"结缘玉简"链接）+ 按完整道号精确搜索，上限 200 位。

### 世界传音（`/game/world-chat`，实时聊天）

- 三个频道：**系统 / 世界 / 宗门**，WebSocket 实时（"正在接引传音……"），支持"加载更早消息"翻历史。
- **系统频道**：发送者为「天道」，自动广播全服事件——破境（踏入「渡劫初期」）、捕获变异灵兽、炼成丹药/法宝（附物品名按钮可点开看属性）、万界金榜（天骄榜排名变动）。本质是**全服动态 feed + 免费广告位**（展示物品制造活跃感）。
- **世界频道**：玩家自由聊天（100 字限制），每条消息带玩家名（点击可"查看并收录道友"= 加好友）+ 境界徽章（「渡劫」圆满等）+ 时间。特殊消息类型：组队招募（带[加入队伍]按钮）、物品展示（[展示物品]按钮）、@道友。实测内容：玩家自发形成**交易市场**（功法按境界明码标价：炼气10万/筑基20万/金丹30万/元婴40万）、喊话卖材料、讨论物价——经济系统完全由玩家驱动。
- **宗门频道**：宗门内部聊天，节奏慢，实测以新人提问（丹毒怎么解、闭关有什么用、突破要备什么）+ 老玩家答疑为主；另有**玩家自建组织**在宗门频道打广告（"修改角色称号 XX·载酒"来入会——利用称号系统实现了玩家公会）。
- 输入区：文本框（0/100）+ [展示物品] + [发送]。

### 借鉴要点

- 聊天按"系统广播 / 世界 / 宗门"三分频道，系统频道全是程序生成的事件 feed，成本低、世界感强。
- 玩家名 + 境界徽章随消息展示，聊天本身就是身份与社交货币。
- 邮件承担公告/补偿/礼包/兑换码四类运营职能，全部用修仙话术包装（传音玉简、结缘玉简）。
- 组队招募直接内嵌聊天流（招募消息自带加入按钮），转化路径极短。

## 五、全场景目录与深度玩法实测（第二轮补充）

### 万界行止（底部导航"展开"，全场景目录）

7 大类 27 个入口，等于游戏站点地图：

- **修行**：每日占卜、洞府灵田、悟道室、阵纹室、灵兽袋、重塑命格（`/game/fate-reshape`，改命的入口）
- **宗门**：宗门、宗门神通（`/game/sect/arena`，流派配装 workspace）
- **历练**：修仙界地图、云游探秘、蜃楼幻境（爬塔）、任务中心
- **争锋**：天骄榜（排行榜）、擂台切磋（PVP）、全部战绩
- **交易**：修仙坊市、鉴宝回收、万界商行、拍卖行
- **见闻**：世界传音、修仙日志（`/game/journal`）、探险札记（副本历史）

### 每日占卜（`/game/divination`）

### 云游探秘 / 野外寻觅 / 战斗系统（重点实测）

**流程**：云游探秘页（选秘境=跳舆图）→ 舆图点地点展开详情 → 进入野外（`/game/wild?nodeId=…`）→ 寻觅灵兽（每次 2 天地灵气，AI 生成遭遇）→ 开战捕捉。

- 寻觅结果：一组 1~3 只灵兽（带等级、成年/幼崽、"暂不可出战"标记），可继续寻觅（放弃该组）或开战。

**战斗系统（回合制指令制，实测 1v3）**：

- 资源四条：气血、护盾、法力、**战意**（0/150，战斗中积累，疑似大招资源）。
- 指令面板：攻击 / 神通 / 器诀（无法宝时禁用）/ 自动 / 防御 / 保护 / 灵兽（无灵兽时禁用）/ 捕捉 / 逃跑，另有放弃战斗。

- **回合顺序：敌方先手、我方后手**（每回合按序：敌→我）。
- 状态效果：隐身（3 回合内不可被选为目标）、剑息。

- **逃跑会失败**（连续 2 次"逃离失败"，有成功率）；**放弃战斗**必退但保留气血法力损耗、灵气不退（确认弹窗明示代价）。
- 战报按回合分组、可折叠展开（"▸ 第 1 回合 4 次行动"），细节按钮看详细数值。
- 实测体感：炼气初期 1 打 3 只 6~12 级灵兽打不动（普攻 7 伤/次，敌方 30+ 伤/回合），新手野外强度偏高，建议组队或先强化再战。

### 装备系统（实测穿戴全套）

### 灵兽系统（实测抓到第一只 + 完整面板）

- **灵兽袋**：容量 0/24，**出战位 0/6**（战斗中可召唤，首发自动入场）；另有灵兽图鉴与灵兽融合。
- **捕捉规则（实测破案）**："暂不可出战"标记 = **灵兽等级超过主人携带上限**（炼气初期带 12 级兽 → 捕捉报"当前条件不满足"；升到炼气中期后 5 级精灵狼成为合法目标）。捕捉耗 15 法力、**有成功率**（满血 6 级兽连败多次；压血线可提高成功率，5 级满血第二次成功）。
- **★ 结束方式决定收获（关键实测）**：捕捉成功显示"已收服，战后加入灵兽列表"——
  - 捕捉后**放弃战斗** = 灵兽丢失（实测两次验证，第一次精灵狼未入袋）；
  - 捕捉后**成功逃跑（已离场）** = 灵兽保留（第二次咪咪成功入袋）。
  - 逃跑有成功率，实测连败 5 次后第 6 次成功；逃跑期间照常挨打。
- **★ 灵兽完整面板（与梦幻西游高度同构）**：
  - 五维**资质**（攻击 941/防御 976/体力 3546/法力 1419/速度 983）+ **成长 1.023**——资质×成长双轴评估；
  - **寿命 1000/1000**（可点击看"寿命与入场规则"）；
  - 五维属性加点（体质/力量/魔力/耐力/敏捷）+ **洗点**按钮；
  - 技能区：**[领悟传承]**、**[洗炼]** 按钮，自带技能可点击看效果（招架）；
  - 操作：改名/设为首发/携带出战/喂养/休养/**放生**；野生标记；携带要求（需炼气初期）；灵兽有自己的修为条（0/238）。
  - → 与 `docs/灵兽合成参考-梦幻西游.md` 的分析完全互相印证：**万界道友的灵兽系统就是梦幻召唤兽体系**。
- **灵兽融合**：两只普通灵兽（均 ≥30 级、符合主人等级与携带要求、移出出战编组）融合为一只新兽，**可预览可能结果，但技能可能变少、资质成长可能变差**——赌博式合成；变异灵兽不可参与。

### 战斗补充机制（第二轮实测修正）

### ★ 账号结算锁案例（第六轮破案，2026-10-12 晨）

昨晚"操作静默失败"的真正原因不是服务器慢，而是**账号级结算锁**：

- 战斗结束（逃跑成功"已离场"、资源已结算）后，页面会渲染"**[结束本次战斗]**"确认按钮；昨晚因加载卡顿没看到该按钮就离开了页面。
- 战斗在服务端保持"待确认"状态 → 全账号写操作被锁（携带灵兽/服用丹药均失败，提示"**战斗或资源结算期间不能操作**"toast——纯文字提示，快照里不可见，容易漏看）。
- 翌日回到该野外地点（`/game/wild?nodeId=SAT_TN_08`），战斗界面仍在第 12 回合"已离场"状态等待确认 → 点击 [结束本次战斗] → 锁解除。
- 解锁后验证：悟道丹服用成功（感悟 22→32，+10）；咪咪携带出战成功（1/6）并设为「首发」。

**对 xuxian 的三条教训**：
1. 战斗/结算结束的**最后一步确认必须有全局入口**（首页红点/悬浮提示"有一场战斗待收束"），不能只依赖战斗页内的按钮；
2. 账号锁存在时应**禁用+明示**所有写操作按钮（含原因），而不是允许点击后静默失败；
3. 锁状态提示要进 DOM（可访问），不能只做一闪而过的 toast。
